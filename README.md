# Sistema Inteligente Basado en Conocimiento y Reglas
## Cálculo de rutas en el sistema de transporte masivo

**Curso:** Inteligencia Artificial
**Integrantes:** Johan Marcelo Mendoza Barrera y Johan David TovarAcevedo

---

## 1. Objetivo del Trabajo

Desarrollar un sistema inteligente en Python que, a partir de una base de
conocimiento representada mediante reglas lógicas, encuentre una ruta válida
entre dos estaciones del sistema de transporte masivo, simulando cómo un
sistema experto razona a partir de hechos y reglas para llegar a una
conclusión.
